# SWYNEX Interactive Dashboard

## Overview

This project was created as part of my Data Analyst Internship at SWYNEX Technologies.

The objective was to build an interactive dashboard using Power BI to analyze an Online Retail dataset and present key business insights through visualizations and KPIs.

## Tools & Technologies

- Power BI Desktop
- Power BI DAX
- Microsoft Excel / CSV
- Data Cleaning & Data Analysis

## Dataset

The dashboard is based on an Online Retail dataset containing information such as:

- Invoice Number
- Stock Code
- Product Description
- Quantity
- Invoice Date
- Unit Price
- Customer ID
- Country

A Revenue column was created using:

`Revenue = Quantity × Unit Price`

## Dashboard Features

The dashboard includes:

- Total Revenue KPI
- Total Orders KPI
- Total Quantity KPI
- Unique Customers KPI
- Monthly Revenue Trend
- Top Products by Revenue
- Revenue by Country
- Interactive Country Filter
- Interactive Month Filter

## Key Learning

Through this task, I gained practical experience in:

- Creating calculated columns and measures using DAX
- Designing interactive Power BI dashboards
- Using slicers for interactive filtering
- Creating KPI cards and business visualizations
- Presenting data-driven insights in a clear and professional format
